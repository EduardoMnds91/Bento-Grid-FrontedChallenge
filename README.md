# Bento-Grid-FrontedChallenge
Frontend Mentor: Bento Grid Solution  This is my solution to the Bento Grid challenge. The primary focus was achieving a pixel-perfect replica of the original design while optimizing visual performance and code maintainability.

Key Technical Highlights:

Semantic HTML5: Built with a focus on meaningful structure.

CSS Grid Mastery: Implemented using grid-template-areas and strategic spans to handle layout complexity without positioning hacks.

Internal Alignment: Leveraged Flexbox to manage the internal distribution of content within each card.

Mobile-First Workflow: Ensured a seamless responsive transition from single-column mobile view to the full desktop bento layout.
